## 2026-06-26 - Sanitization of CSS Style Elements from Dynamic Chart Configs
**Vulnerability:** In `src/app/components/ui/chart.tsx`, `ChartStyle` rendered dynamic chart IDs, config keys, and color variables directly into `<style dangerouslySetInnerHTML=... />` without sanitization, allowing potential CSS injection or style breakout attacks if dynamic keys/colors contain unescaped user input or raw payloads.
**Learning:** React elements like `<style>` with `dangerouslySetInnerHTML` bypass standard JSX auto-escaping, treating inner HTML strings as raw CSS rules. Static prefix rules like `.dark` must be preserved, while dynamic identifiers (IDs and variable keys) and variable values must be explicitly sanitized.
**Prevention:** Use `sanitizeCSSIdentifier` (stripping characters outside `/a-zA-Z0-9-_/g`) for keys/IDs and `sanitizeCSSValue` (stripping HTML tags, comment markers, backslashes, delimiters `{`, `}`, `;`, `<`, `>`, and function calls like `url(` or `expression(`) for CSS values before string interpolation into style blocks.
