## 2026-06-27 - ChartStyle CSS Injection Vulnerability
**Vulnerability:** CSS injection and potentially Cross-Site Scripting (XSS) via dynamic theme styling configuration in the `ChartStyle` component. Under certain scenarios where custom configurations or identifiers (e.g. key, ID, color values) are dynamically injected into a `<style>` element using `dangerouslySetInnerHTML`, an attacker with control over these parameters can break out of the selector block (e.g. using semicolons, brackets, or backslashes) or inject malicious properties such as `url(javascript:...)`, `expression(...)`, or a closing `</style>` tag.
**Learning:** React components that inject raw strings into `<style dangerouslySetInnerHTML={{ __html: ... }}` elements are not automatically sanitized by React, as React bypasses its standard HTML entity encoding for raw injection.
**Prevention:** Centralize CSS sanitization patterns. Use dedicated CSS validation functions: limit identifiers (such as keys and IDs) to alphanumeric characters, dashes, and underscores; for values (like colors or styling values), explicitly block characters or keywords that break standard rules (such as `url(`, `expression(`, `javascript:`, and closing `</style>` tags), and strip delimiters like `;`, `}`, and `\`.
