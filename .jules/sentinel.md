## 2025-02-18 - CSS Injection in ChartStyle Component
**Vulnerability:** The `<ChartStyle>` component inside `src/app/components/ui/chart.tsx` rendered style tags directly with `dangerouslySetInnerHTML`. Since identifiers (keys) and color strings from the `config` object were injected without sanitization, an attacker who could control these fields could breakout of the CSS rules and perform XSS/CSS injection (e.g., loading remote tracking pixels via `url()`, executing JS, or breaking styles completely).
**Learning:** React elements utilizing `dangerouslySetInnerHTML` for dynamic CSS or HTML can easily introduce style-injection/XSS holes if variables are not thoroughly sanitized. Even seemingly harmless style properties like "color" or custom keys can be manipulated to break out of selectors using brackets `]`, braces `}`, semi-colons `;`, or remote functions like `url()`.
**Prevention:** Always sanitize dynamic inputs injected into `<style>` blocks. Ensure identifiers are strictly alphanumeric (using `/[^a-zA-Z0-9-_]/g`), and strictly sanitize values by blocking remote/dynamic URL resources and stripping syntax-breaking characters like `;`, `}`, and `\`. Use centralized utility functions for these checks.
