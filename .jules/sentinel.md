## 2026-07-23 - ChartStyle CSS Injection Vulnerability Fix
**Vulnerability:** In `ChartStyle` in `src/app/components/ui/chart.tsx`, style elements were rendered with `dangerouslySetInnerHTML` by interpolating keys and color values without sanitization. An attacker supplying dynamic configuration could inject arbitrary CSS selectors or properties, leading to style leakage, layout disruption, or potential CSS-based data exfiltration.
**Learning:** React components that inject raw dynamic styles using `dangerouslySetInnerHTML` bypass standard security escaping. Even when limited to CSS variable injection, missing boundaries on identifiers and colors allows syntax breakout (e.g., using curly braces, semicolons, backslashes, or `</style>` tags).
**Prevention:** Centralize CSS property and value sanitization. Always filter out invalid characters from CSS identifiers/property keys (using `/[^a-zA-Z0-9-_]/g`), and strip break-out characters (like `;`, `}`, and `\`) or block dangerous keywords (like `url(`, `expression(`, `javascript:`, `</style>`) from style values before injecting them into a stylesheet.
