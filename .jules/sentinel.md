## 2025-02-14 - CSS/XSS Injection Vulnerability in Shadcn ChartStyle Component
**Vulnerability:** In the `ChartStyle` component in `src/app/components/ui/chart.tsx`, the chart identifier and key/color properties were injected directly into a `<style>` tag using `dangerouslySetInnerHTML` without sanitization. An attacker supplying malicious chart configurations (e.g. keys/colors) could execute arbitrary Javascript via style breakouts (e.g., using `</style>` tags or nested CSS selectors and `url(javascript:...)`).
**Learning:** Dynamically generated stylesheets or custom `<style>` blocks populated from dynamic data are vulnerable to CSS injection if the variables are not validated. Since shadcn charts allow mapping dynamic keys or dynamic color palettes to CSS variables, they represent a hidden XSS vector in many React codebases.
**Prevention:** Standardize a strict CSS sanitization utility to strip characters outside `[a-zA-Z0-9-_]` for CSS identifiers, and filter color values to block critical breakout vectors such as `url(`, `expression(`, `javascript:`, and `</style>`, while stripping characters like `;`, `}`, and `\`. Use this sanitization in any component dynamically writing styles.
