## 2025-07-21 - [ChartStyle CSS Injection Prevention]
**Vulnerability:** The ChartStyle component injected user/config-provided chart id, keys, and colors directly into an HTML `<style>` element using `dangerouslySetInnerHTML`. An attacker providing a malicious configuration (such as `id="chart-id; body { background: red; }"` or color `red</style><script>alert(1)</script>`) could break out of the style block and inject arbitrary CSS or JavaScript (XSS).
**Learning:** React's `dangerouslySetInnerHTML` combined with dynamically generated CSS rules allows raw string injection bypasses if inputs are not strictly sanitized. Dynamic identifiers and CSS variables require strict sanitization (such as alphanumeric character whitelist for identifiers and regex-based blocklisting for property values) before embedding.
**Prevention:** Centralize CSS sanitization functions: use `sanitizeCSSIdentifier` to restrict class names, IDs, and property keys to `/[a-zA-Z0-9-_]/` and `sanitizeCSSValue` to strip characters like `;`, `}`, `\` and block pattern injections like `url()`, `expression()`, `javascript:`, or `</style>` tags.
