## 2026-06-27 - [Chart CSS Injection Mitigation]
**Vulnerability:** The dynamic `<style>` block generated in the shadcn Chart component (`ChartStyle`) was vulnerable to CSS injection. It injected raw `id`, config keys, and item colors using `dangerouslySetInnerHTML` without proper validation or sanitization, potentially allowing an attacker to inject arbitrary CSS, breakout of the style context, or execute scripts/exfiltrate data.
**Learning:** React's protection against XSS (automatic escaping) is bypassed when using `dangerouslySetInnerHTML`. Inline `<style>` elements must be carefully constructed to ensure injected keys and values cannot break the CSS syntax structure or inject dangerous protocols like `javascript:`.
**Prevention:** Always sanitize identifiers used in custom CSS selectors by stripping out spaces, punctuation, or escaping characters. Cleanse values of dangerous tokens (like `url(`, `expression(`, `javascript:`, or `</style>`) and strip out CSS termination/breaking characters (like semicolons, curly braces, and backslashes) before rendering them.
