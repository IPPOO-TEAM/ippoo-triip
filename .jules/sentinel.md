## 2025-05-14 - [CSS Injection in Chart Component]
**Vulnerability:** The `ChartStyle` component used `dangerouslySetInnerHTML` to inject dynamic CSS into a `<style>` tag without sanitizing identifiers (IDs and config keys) or values (colors). This allowed an attacker to break out of the CSS block and execute arbitrary JavaScript (XSS) via `</style><script>...` or use dangerous CSS properties like `expression()` or `url()`.
**Learning:** Dynamic CSS generation using `dangerouslySetInnerHTML` is a common but risky pattern in modern UI libraries (like shadcn/ui charts). It requires strict sanitization of both CSS identifiers and values to prevent injection.
**Prevention:** Always sanitize any user-controlled input that is used to build dynamic CSS. Use a strict regex for identifiers (e.g., `/[^a-zA-Z0-9-_]/g`) and block dangerous keywords like `url(`, `javascript:`, and `</style>` in values, while also stripping characters like `;` and `}` that allow declaration breakout.
