## 2026-10-31 - Dynamic CSS Injection in ChartStyle and Safe Selector Sanitization
**Vulnerability:** In `src/app/components/ui/chart.tsx`, `ChartStyle` dangerously interpolates dynamic chart IDs, configuration keys, and CSS color values directly into a raw `<style>` tag via `dangerouslySetInnerHTML` without escaping, enabling CSS breakout and XSS.
**Learning:** Upstream Figma Make updates can overwrite custom repository files and revert security sanitizers. Furthermore, dynamic CSS sanitization must differentiate between untrusted dynamic inputs (chart IDs, CSS variables, and colors) and trusted internal CSS prefixes (such as `.dark`): applying identifier stripping across the entire selector corrupts valid CSS class dot prefixes.
**Prevention:** Centralize dynamic CSS sanitization in `src/app/utils/security.ts` to strictly sanitize dynamic identifiers (`/[^a-zA-Z0-9-_]/g`) and strip dangerous delimiters/functions (`{`, `}`, `;`, `<`, `>`, `url()`, `expression()`), while preserving trusted static selectors and standard CSS color keywords (e.g., `burlywood`). Verify dynamic CSS generation with automated unit tests in `src/app/__tests__/security.test.ts`.
