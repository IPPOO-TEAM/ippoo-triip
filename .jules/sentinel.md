## 2026-06-27 - ChartStyle CSS Injection
**Vulnerability:** The ChartStyle component in chart.tsx dynamically rendered raw style strings with unsanitized chart config keys, chart ID, and color values using `dangerouslySetInnerHTML`. This made the component susceptible to CSS injection if values or keys originated from or were influenced by untrusted user data.
**Learning:** CSS injection within HTML `<style>` blocks can be used to execute cross-site scripting (XSS) via legacy techniques (like `expression()`), exfiltrate sensitive data via loaded background resources (like `url()`), or hijack elements on the page by breaking out of selectors. Directly interpolating properties into CSS templates without strict whitelist/regex sanitization is highly risky.
**Prevention:** Always use regex-based sanitization and strict validation before injecting dynamic strings into `<style>` tags via `dangerouslySetInnerHTML`. Restrict CSS identifiers strictly to alphanumeric characters plus safe separators (`-`, `_`), and strictly validate CSS values (like colors or sizing) to reject hazardous payloads containing `url(`, `expression(`, `javascript:`, or trailing tags while stripping breaking characters like `;`, `}`, and `\`.
