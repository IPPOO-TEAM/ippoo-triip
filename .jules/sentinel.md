## 2026-06-26 - ChartStyle CSS/XSS Injection Vulnerability
**Vulnerability:** Dynamic class name, ID, and color values were interpolated directly into raw `<style>` blocks using `dangerouslySetInnerHTML` in the `ChartStyle` component without sanitization. This allowed attackers to craft malicious chart config inputs to break out of the style rule context and execute arbitrary CSS injection or script execution (XSS).
**Learning:** Raw dynamic style blocks must never be populated with unvalidated keys or values. Even when React prevents traditional script tags, CSS style rules can be escaped using characters like `;` and `}` to inject malicious code or overwrite other page elements.
**Prevention:** Always sanitize dynamic identifiers and color values before injecting them into CSS/style blocks. Use strict regular expressions to limit identifiers to simple alphanumeric values (plus hyphen/underscore) and filter values to eliminate potential breakouts (`url(`, `expression(`, `javascript:`, `</style>`, `;`, `}`, `\`).
