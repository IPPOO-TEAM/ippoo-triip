## 2026-06-26 - ChartStyle CSS Injection Vulnerability
**Vulnerability:** Dynamically injected chart styling identifiers and theme colors within `<style>` blocks inside the `<ChartStyle>` component were vulnerable to CSS breakout and injection attacks due to using `dangerouslySetInnerHTML` without proper identifier or value sanitization.
**Learning:** React's standard protections do not apply to dynamic `<style>` block strings parsed via `dangerouslySetInnerHTML`. Malicious chart keys or user-controlled color configurations could break out of rule scopes to inject external elements or arbitrarily style/manipulate page layouts.
**Prevention:** Always restrict dynamically rendered CSS identifiers using strict regex limits, stripping non-alphanumeric/hyphen/underscore characters. For CSS color values, strip semicolon delimiters, close braces, and backslashes, while blocking dangerous functions such as `url()`, `expression()`, `javascript:`, or styling breakouts via `</style>`.
