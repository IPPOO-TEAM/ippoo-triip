## 2025-02-15 - ChartStyle CSS Injection Vulnerability
**Vulnerability:** The ChartStyle component in `src/app/components/ui/chart.tsx` generated inline CSS inside a `<style>` element using `dangerouslySetInnerHTML`. It directly interpolated chart identifiers (`id`), theme config keys (`key`), and CSS color values (`color`) without any form of sanitization. An attacker who could control the config or ID could inject malicious CSS rules, potentially leading to Cross-Site Scripting (XSS) or data exfiltration.
**Learning:** React elements using `dangerouslySetInnerHTML` bypass standard JSX output escaping. When rendering dynamic style blocks, arbitrary user-controlled property names, IDs, or CSS values can break out of the style context if standard delimiters like semicolons `;`, curly braces `}`, or backslashes `\` are not sanitized.
**Prevention:** Centralize CSS sanitization utilities like `sanitizeCSSIdentifier` (regex-based sanitization rejecting non-alphanumeric chars) and `sanitizeCSSValue` (blocking `url(`, `expression(`, `javascript:`, and style tags, and stripping syntax delimiters) to filter any dynamic inputs before interpolation into any dynamic CSS/style blocks.
