## 2026-11-01 - Dynamic CSS Injection in ChartStyle Component
**Vulnerability:** Unsanitized dynamic values (`id`, `key`, `color`) were directly interpolated into a raw CSS string inside a `<style>` element using `dangerouslySetInnerHTML` in `ChartStyle`.
**Learning:** React components employing `dangerouslySetInnerHTML` to render dynamic CSS blocks bypass standard JSX auto-escaping, permitting CSS injection and DOM XSS when untrusted input contains structural CSS delimiters (`{`, `}`, `;`) or closing `</style>` tags. Furthermore, automated exports from Figma Make can overwrite application files, inadvertently stripping out security sanitizers and test suites.
**Prevention:** Always sanitize dynamic identifiers to safe alphanumeric/hyphen/underscore tokens and CSS property values by stripping HTML tags, comments, structural delimiters, and unsafe function execution keywords (`url(`, `expression(`, `javascript:`) before embedding them in CSS style tags. Retain trusted static selectors (like `.dark`) unsanitized to prevent breaking standard CSS rules.
