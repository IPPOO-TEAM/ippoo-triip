## 2025-07-19 - CSS Injection via Dynamic Recharts ChartStyle Component
**Vulnerability:** The ChartStyle component in the recharts dashboard UI was vulnerable to CSS injection since it directly embedded unsanitized chart config keys, chart IDs, and color values into a `<style>` block using `dangerouslySetInnerHTML`.
**Learning:** React components that generate dynamic inline CSS rules inside `<style>` tags bypass standard React JSX HTML entity escaping. Without sanitization, any malicious input injected into chart options or theme/color properties can lead to CSS-jacking, stylesheet breakout, and potentially Cross-Site Scripting (XSS).
**Prevention:** Centralize CSS sanitization helper functions (`sanitizeCSSIdentifier` and `sanitizeCSSValue`) using strict regex-based patterns. Ensure all identifiers allow only alphanumeric characters, hyphens, and underscores, while style values strip rule breakers like semicolons/brackets and completely block malicious functions such as `url()`, `expression()`, or `javascript:`.
