1) Style visuel recommandé (cohérence)
•	Illustrations “flat” ou semi-3D légères, couleurs chaudes (ocres, verts, bleus), contrastes forts, traits simples.
•	Photographies réelles pour la confiance (chauffeurs, colis, preuves), mais illustrations pour l’onboarding et les écrans vides.
•	Motifs subtils africains (wax, bogolan, kente) en arrière-plan très léger (5–10% d’opacité) pour éviter l’effet “trop décoratif”.
•	Icônes claires, universelles, inspirées du contexte local (moto-taxi, tricycle, marché).
________________________________________
2) Types d’images par section de l’app
A) Inscription / Connexion (confiance)
•	Illustrations : téléphone + OTP, bouclier sécurité, empreinte/FaceID.
•	Photos (optionnel) : visage souriant “portrait local” (diversité), style professionnel et neutre.
B) Home (repères locaux)
•	Bannières promotionnelles (illustrations ou visuels photo + overlay) :
•	scènes urbaines africaines (rond-point, grandes artères, campus, marchés).
•	Pictos services :
•	moto, tricycle, voiture, mini-bus, pickup, colis, covoiturage, wallet.
•	Mini-illustrations “chauffeurs à proximité” sur carte (avatars + véhicules).
C) Commander une course (transport de personnes)
•	Icônes / silhouettes de véhicules locales :
•	Moto-taxi, tricycle (keke), voiture, mini-bus (gbaka / minibus selon pays).
•	Images de contexte (illustrations) :
•	“point de départ” (maison, campus), “marché”, “gare routière”.
•	Pendant la course :
•	photo chauffeur (réelle) + photo véhicule (réelle) + plaque (graphique).
•	icônes : partage position, appel, chat.
D) Livraison / Colis
•	Photographies obligatoires :
•	photo du colis (prise par l’utilisateur) + preuve livraison (photo + signature).
•	Illustrations :
•	colis “fragile”, “document”, “lourd” (pictos explicites).
•	parcours “retrait → en route → livré” (timeline illustrée).
E) Transport de biens / gros colis
•	Icônes : pickup, camionnette, tricycle cargo, diable de manutention.
•	Illustrations : déménagement léger, chargement/déchargement (main-d’œuvre).
•	Badges visuels : “assurance”, “manutention incluse”, “paiement après”.
F) Commandes groupées
•	Illustrations :
•	groupe de personnes (étudiants, commerçants, ménages) autour d’une liste/ panier.
•	QR code + partage de lien (icônes).
•	Visuels : “un point de livraison” (pin unique sur carte + plusieurs avatars).
G) Covoiturage
•	Illustrations :
•	trajet “Campus → Maison”, “Bureau → Quartier”.
•	voiture avec 2–4 silhouettes, notion de “sièges”.
•	Badges : “trajet régulier”, “partage paiement”.
H) IPPOO CASH / Paiements
•	Icônes :
•	wallet, QR code, mobile money, transfert, PIN.
•	Images :
•	screenshots stylisés (mockups) ou illustrations de billets/pièces sans trop de réalisme (éviter confusion légale).
•	Micro-illustrations : “solde”, “recharge”, “historique”.
I) Historique / Factures
•	Icônes : reçu, PDF, téléchargement, filtre calendrier.
•	Illustrations “empty states” : “aucune course”, “aucune livraison”.
J) Notifications
•	Pictogrammes :
•	course acceptée, chauffeur arrivé, colis livré, promo, message.
•	Illustrations petites (optionnel) pour les gros événements (bonus, promo).
K) Profil / Sécurité / Vérification
•	Photos :
•	photo de profil utilisateur (réelle).
•	documents (KYC) sous forme d’icônes + cadre photo.
•	Illustrations :
•	bouclier/lock, OTP, biométrie, masquage numéro.
L) Support & Aide
•	Illustrations :
•	casque support, chat, centre d’aide.
•	Images :
•	catégories avec pictos (litige, paiement, trajet, colis).
________________________________________
3) Banque d’images “africaine” (ce qu’il faut représenter)
Pour ancrer localement sans cliché :
•	Lieux : campus, marchés, quartiers résidentiels, axes routiers, stations, devantures.
•	Personnes : diversité (âges, styles vestimentaires), chauffeurs pro (gilet, casque), commerçants, étudiants.
•	Véhicules : motos, tricycles, mini-bus, pickup/camionnette (modèles courants localement).
•	Objets : cartons, sacs, paniers, documents, balances/poids, scellés.
________________________________________
4) Formats à prévoir (pratique)
•	SVG : icônes + illustrations (léger, adaptable).
•	PNG/WebP : photos + bannières promo.
•	Lottie/animations (optionnel) : onboarding, “recherche chauffeur”, “livraison en route”.
